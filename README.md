# 我的数据分析作品集

你好！这个仓库包含了我独立完成的两个数据分析项目，展示了从数据采集、清洗、建模到可视化看板的完整能力。

## 项目列表

### 1. A股多行业投资价值分析看板
- **简介**：针对15家A股上市公司（覆盖7大行业），构建三因子加权评分模型，评估投资价值。
- **技术栈**：Python (Pandas, NumPy, Matplotlib) | 交互式看板 (HTML, Chart.js)
- **演示链接**：[点击查看看板](https://elara-xie.github.io/portfolio/dashboard.html)

### 2. 用户画像分析与监控看板
- **简介**：生成并分析300条模拟电商用户数据，构建画像分析仪表板与监控大屏。
- **技术栈**：Python (数据生成) | Streamlit | Plotly
- **演示链接**：[用户画像分析](https://elara-xie.github.io/portfolio/user_profile_analysis.html) | [数据监控大屏](https://elara-xie.github.io/portfolio/user_monitor_dashboard.html)
